Identified Root Cause & Evidence

JVM heap was configured with -Xmx896m inside a container limited to 1024MiB. Heavy batch deserialization caused direct off-heap buffer allocations and thread stack expansion, exceeding the Kubernetes cgroup limit and triggering Linux kernel OOM killer (exit code 137).

Telemetry Evidence Chain

SIGNAL: JFR OLD GEN HEAP
Tenured pool grew 92% in 180s before sudden pod termination.
SIGNAL: K8S CGROUP OOM
Kernel dmesg logged task killed with total-vm:1.4GB, anon-rss:1023MB.

Actionable Remediation Plan

Immediate Mitigation < 5 mins

Increase container memory limit to 2048MiB via kubectl patch to prevent immediate crash loops during peak load.

kubectl set resources deployment checkout-service -c app --limits=memory=2048Mi
Permanent Architectural Fix Sprint Task

Tune JVM -XX:MaxRAMPercentage=75.0 and stream JSON payloads instead of loading complete documents into memory.

Kruize Recommendation ID: KRZ-REC-9482-OPTIMAL

The Core Diagnostic Signals

Causa does not guess from logs alone. It correlates distinct production signals to pinpoint the exact failure mechanism.

01
K8s MCP

Pod Status & Events

Extracts container restart count, exit codes (137, 143), phase transitions, and readiness probe flap history.

lastState.terminated.exitCode: 137
02
Prometheus

Resource Utilization Metrics

Pulls real-time metrics and fetches trends leading up to incident.

container_memory_working_set_bytes
03
Stream Logs

Application Logs

Detects Java stack traces, OutOfMemoryError, DirectMemory limits, socket leaks, and fatal framework aborts.

java.lang.OutOfMemoryError: Java heap
04
Framework Specific MCP

Custom MCPs/ Quarkus

Collects data from custom mcps such as quarkus mcp server.

jvm_total_memory_used
05
Jafra MCP

Jafra Deep Profiling

Analyzes GC pause distributions (G1, ZGC, Shenandoah), Tenured Generation trends, thread allocations & parked locks.

jdk.GarbageCollection (pause: 4800ms)
06
Kruize MCP

Kruize Autotune Optimizer

Provides autonomous rightsizing recommendations comparing current pod requests/limits with optimal JVM footprints.
